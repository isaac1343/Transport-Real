# Transport Coordination System

A complete Next.js web application for employee transport planning and coordination.

## Features

### Employees
- Sign up as transport users
- Log in daily
- Sign up for today's transport
- View boarding and drop-off status

### Vendor
- Log in
- Search employees by employee ID
- See error if employee number is missing
- Confirm whether employee signed up today
- Check employee into a specific car
- Select vehicle by number plate
- Mark employee as dropped off
- View all employees who signed today

### Admin
- Log in
- Add new employees
- Add cars
- Add drop-off points
- View all employees
- View cars and capacity
- View employees boarded by specific car
- View full transport utilization report
- Estimate how many cars are needed for a specific day
